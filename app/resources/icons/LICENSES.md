# Icon sources and licenses

Every icon here is a published, human-made icon, rasterized to a white mask
by `app/tools/make_icons.py` (the app tints it when drawing). None was drawn
or generated by this project. The same icons make up the app icon
(`app/resources/icon/icon.png`, `app/sce_sys/icon0.png`) and the LiveArea
images (`app/sce_sys/livearea/contents/`), with text set in M PLUS Rounded 1c.
